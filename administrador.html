Flujo recomendado

1. Crea o edita tus proyectos aquí.
2. Descarga proyectos.json desde la sección Datos / JSON.
3. Sube ese archivo a data/proyectos.json dentro de tu repositorio de GitHub.
4. GitHub Pages actualizará el portafolio.
